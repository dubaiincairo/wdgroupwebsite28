# SwissBlue FSE

Custom **WordPress 7.0 Full-Site-Editing (FSE) block theme** for **SwissBlue
Hospitality Group** — a multi-property luxury hospitality brand in Saudi Arabia.

The theme implements the **Brand New Yanolja Cloud Solution Design System
(BNY-CSDS)**. That document — [`DESIGN_SYSTEM.md`](./DESIGN_SYSTEM.md) — is the
**single source of truth** for every colour, spacing value, border-radius,
shadow, component pattern, and animation. It is read-only reference and must
never be modified.

- **Default language:** Arabic (`ar_SA`, RTL)
- **Secondary language:** English (`en_US`, LTR)
- **Text domain:** `swissblue-fse`
- **Requires:** WordPress 7.0+, PHP 8.3+, Node 20 LTS

## Status

**Phases 1–6 complete.** The theme is feature-complete: design tokens and
`theme.json`, 10 custom blocks, ACF field groups, Block Bindings, all
templates and parts, Hotel JSON-LD schema, Polylang integration, and the
letsbook.me booking bridge are in place. Before going live, install on
WordPress 7.0 staging, run `npm run build`, and smoke-test in the editor.

## Install & develop

```bash
npm install      # install build tooling
npm run dev      # Vite watch build (assets/ -> dist/)
npm run build    # production build
```

Required plugins (assumed installed — never bundled or installed by the theme):
**ACF Pro**, **Polylang**, **RankMath**.

## Folder structure

```
swissblue-fse/
├── DESIGN_SYSTEM.md   read-only design reference (BNY-CSDS)
├── style.css          theme header
├── functions.php      loads inc/ modules + registers theme supports
├── parts/             template parts (header, footer, promo ribbon)
├── templates/         block templates
├── patterns/          block patterns
├── blocks/            10 custom blocks (dynamic, server-rendered)
├── assets/            css/ (tokens + Tailwind entry), js/, fonts/
├── inc/               PHP modules (CPTs, taxonomies, blocks, schema…)
├── languages/         .pot / .po / .mo translation files
├── bin/               deploy helper (build-zip.sh)
└── dist/              compiled assets (generated by Vite; git-ignored)
```

## Build a theme ZIP

Run the helper script — it installs dependencies, builds assets, and packages
an installable ZIP next to the theme folder:

```bash
bin/build-zip.sh
```

Upload the ZIP via **Appearance → Themes → Add New → Upload Theme** on the
WordPress 7.0 staging environment.
